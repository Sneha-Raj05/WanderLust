# 🌍 Wanderlust – Travel Booking Platform

*Wanderlust* is a full-stack web application for discovering and booking stays across various destinations. Designed with clean UI, secure authentication, and real-time map integration using Google Maps, it's inspired by platforms like Airbnb and Booking.com .

## ✨ Features

- 🏠 Browse listings with photos, price, and descriptions
- 📍 Google Maps integration for location preview
- ➕ Create, edit, and delete listings
- 🔒 Secure login/logout (Passport.js)
- 📸 Upload images using Multer and Cloudinary
- 📬 Flash messages for user feedback
- 📦 Session storage using MongoDB (MongoStore)
- ⚙ Environment-based config with .env file
- 📱 Fully responsive design


## 🛠 Tech Stack

| Layer       | Tech Used                                                                   |
|-------------|---------------------------------------------------------------------------- |
| *Frontend*  | HTML, CSS, JavaScript, Bootstrap / Tailwind, EJS templating                 |
| *Backend*   | Node.js, Express.js                                                         |
| *Database*  | MongoDB, Mongoose                                                           |
| *Auth*      | Passport.js (Local Strategy), Express-session, connect-mongo                |
| *Cloud*     | Cloudinary (for image uploads)                                              |
| *Map*       | Leaflet for location integration                                    | 
| *Middleware*| Express Router, Flash Messages, Custom Middlewares                          |
| *Uploads*   | Multer for handling multipart form-data                                     |
| *Storage*   | MongoDB session store using connect-mongo                                   |
| *Env *      | Managed using dotenv package                                                |
